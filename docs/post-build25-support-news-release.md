# Post-Build-25 Support, News, and Knowledge Base Preparation

This release patch extends the production Build 25 application without starting Build 26 implementation.

## Included

- Public **Support HDC** page under the SaiCore name.
- PHP-only support policy covering one-time contributions, recurring support, and corporate sponsorships.
- Multi-channel payment strategy with provider-fee disclosure and no fabricated receiving destinations.
- Public **Contact Owner** page using `saicore.holdings@gmail.com`.
- Public **HDC News** feed for announcements, feature releases, maintenance notices, and consent-based supporter recognition.
- Owner / Super Admin / Admin in-app publishing controls; Moderator is not authorized to publish.
- Recognition publication requires explicit confirmation that the person or organization agreed to public recognition.
- Publishing mutations are audit logged.
- Public **Knowledge Base** shell prepared for Build 26, with search and knowledge functionality intentionally inactive until the Build 26 authority, article, review, feedback, and Nexus knowledge work is implemented.

## Release boundaries

- Financial intake remains inactive until the Owner supplies verified SaiCore receiving details for each selected channel.
- Support never purchases trust, ratings, verification, moderation exceptions, dispute outcomes, ranking, private data, or product decisions.
- The Knowledge Base shell does not fabricate articles, search results, troubleshooting answers, or Nexus responses.
- Existing service workflow authorization, transaction isolation, migrations, backup/restore, and Build 25 application behavior remain protected by the normal HDC CI gates.
