DEFERRED / NON-BLOCKING WORK
============================
1. Android application identity
   Current namespace/applicationId remains com.example.hdc_app. Choose a permanent unique identifier before public/external Android beta distribution. This was not invented automatically because changing it becomes an app identity decision.

2. Android release signing
   Release currently points to the debug signing configuration. Configure a real protected release keystore before external distribution.

3. Server migration of local repositories
   Existing onboarding/service request/proposal/transaction/private conversation repositories still use SharedPreferences. Bulk conversion was deferred because these are planned for staged server-backed repository adapters; changing all persistence during the auth cutover would add unnecessary regression risk.

4. SharedPreferences API modernization
   Existing repositories use the legacy SharedPreferences API. Modernization can be done during the same staged data-repository migration rather than performing two persistence rewrites.

5. Password reset
   Backend reset/delivery is not implemented yet and the UI explicitly treats it as pending.

6. Sample technician discovery fixtures
   lib/models/technician.dart and lib/data/sample_technicians.dart contain obvious demo ratings/job counts. These are sample discovery fixtures, not authenticated technician account reputation. They should be replaced with real server data or clearly demo-labeled before the public marketplace contains real technician listings.

7. Existing planned placeholders
   Role onboarding preview contains an intentional later-destination placeholder. Product Passport has timeline/audit integration marked coming soon. These are feature-completeness items rather than auth blockers.

8. Windows secure storage build prerequisite
   If the Windows build environment reports an ATL/C++ toolchain error while compiling secure storage, install the relevant Visual Studio C++/ATL component and rebuild.
